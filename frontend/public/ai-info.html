XDDAPI：统一 AI API 接入与用量管理

XDDAPI 是面向个人开发者和团队的 AI API 网关服务。用户可以通过统一的 API 接入服务运营方配置的 AI 模型，并在一个平台管理 API 密钥、上游账号调度、请求用量和消费额度。

主要功能

  • 统一 API 入口：使用平台生成的 API 密钥，按平台文档调用已开放的模型服务。
  • 多上游账号调度：运营方可以配置多个上游账号，由平台按可用性和调度规则处理请求。
  • 密钥与额度管理：创建和管理调用密钥，查看额度、消费和使用记录。
  • 运营管理：管理员可管理账号、分组、模型可用范围、用户和运行状态。

适用场景

  • 希望通过一个 API 接入服务中已配置的多个 AI 模型的开发者。
  • 需要为团队成员分配密钥、额度并查看用量的团队。
  • 需要集中管理多个上游账号和模型访问策略的服务运营者。

使用前须知

具体可用模型、注册状态、价格、额度、服务条款和访问资格由 XDDAPI 服务运营方配置，并可能调整。请以网站内当前展示的信息为准。本页面不代表任何模型提供商的官方服务或背书。
